# Kasier De Leon Portfolio

## Run locally
```bash
npm install
npm run dev
```

Open http://localhost:3000

## Add certificates
Put your certificate images inside:
`public/certificates/`

Use these filenames:
- ccna.jpg
- data-analytics.jpg
- hardware.jpg
- operating-systems.jpg
- linux.jpg
- packet-tracer.jpg

Then deploy the project to Vercel.
